1. Flash the ISO to USB & boot

Download the official Arch Linux image from https://archlinux.org/download/ (reference: official docs). Back up anything on your USB stick first because flashing overwrites it.

balenaEtcher (Windows, macOS, Linux)

  1. Open balenaEtcher, click Flash from file, and pick the downloaded Arch Linux ISO.
  2. Click Select target and choose your USB flash drive (verify the size/name so you do not pick an external backup drive).
  3. Click Flash! and wait for flashing and verification to complete.

Rufus (Windows)

  1. Plug in the USB stick, open Rufus, and select your USB drive under Device.
  2. Click SELECT next to Boot selection and choose your Arch Linux ISO file.
  3. Click START, confirm the data-erase warning, and wait until Rufus shows Ready.

Booting the USB: Restart and press your boot menu key (often F12, F11, F8, or Esc), select the USB drive, and disable Fast Boot / Secure Boot / Windows Fast Startup if needed.

2. Arch Linux CLI installation commands (pacstrap & chroot)

After flashing the Arch ISO and booting in UEFI mode, verify internet connectivity, partition and format your EFI and root partitions, mount root at /mnt and EFI at /mnt/boot/efi, then run these commands:

  1. Partition and format disks (e.g. FAT32 for EFI at /mnt/boot/efi and ext4/Btrfs for /mnt), then install base packages with pacstrap and generate /etc/fstab with genfstab -U /mnt >> /mnt/etc/fstab.
  2. Enter the new system with arch-chroot /mnt, set the timezone (/usr/share/zoneinfo/... -> /etc/localtime) and hardware clock, uncomment UTF-8 locales in /etc/locale.gen, run locale-gen, and write /etc/locale.conf and /etc/hostname.
  3. Set the root password with passwd, create a user and enable NetworkManager, install and configure GRUB (grub-install + grub-mkconfig), exit chroot, unmount /mnt, and reboot.

Commands for Arch Linux

pacstrap -K /mnt base linux linux-firmware networkmanager vim grub efibootmgr genfstab -U /mnt >> /mnt/etc/fstab arch-chroot /mnt ln -sf /usr/share/zoneinfo/UTC /etc/localtime hwclock --systohc sed -i 's/^#en_US.UTF-8 UTF-8/en_US.UTF-8 UTF-8/' /etc/locale.gen locale-gen echo 'LANG=en_US.UTF-8' > /etc/locale.conf echo 'archbox' > /etc/hostname passwd grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB grub-mkconfig -o /boot/grub/grub.cfg systemctl enable NetworkManager exit umount -R /mnt reboot

3. After installation

Arch & pacman rolling-release notes

Arch and Arch-based distros update continuously. Keep a fallback kernel such as linux-lts installed and avoid partial upgrades.

sudo pacman -Syu

Practical tips for Arch Linux

1. Always run genfstab -U /mnt >> /mnt/etc/fstab and inspect /mnt/etc/fstab before rebooting.

2. Install linux-lts alongside linux so you have a fallback kernel if a rolling kernel update misbehaves.

4. Troubleshooting

USB not booting: Re-flash the ISO with balenaEtcher or Rufus, try another USB port, and check UEFI boot priority and Secure Boot / Fast Boot settings.

Installer or boot issue: Check the official Arch Linux documentation for exact partition, driver, or bootloader steps, and save your own notes in the sidebar.
