1. Flash the ISO to USB & boot

Download the official Void Linux image from https://voidlinux.org/download/ (reference: official docs). Back up anything on your USB stick first because flashing overwrites it.

balenaEtcher (Windows, macOS, Linux)

  1. Open balenaEtcher, click Flash from file, and pick the downloaded Void Linux ISO.
  2. Click Select target and choose your USB flash drive (verify the size/name so you do not pick an external backup drive).
  3. Click Flash! and wait for flashing and verification to complete.

Rufus (Windows)

  1. Plug in the USB stick, open Rufus, and select your USB drive under Device.
  2. Click SELECT next to Boot selection and choose your Void Linux ISO file.
  3. Click START, confirm the data-erase warning, and wait until Rufus shows Ready.

Booting the USB: Restart and press your boot menu key (often F12, F11, F8, or Esc), select the USB drive, and disable Fast Boot / Secure Boot / Windows Fast Startup if needed.

2. Void Linux void-installer, XBPS & runit commands

Boot the Void live image (glibc or musl), log in as root (password voidlinux), and run void-installer:

  1. In void-installer, configure Keymap, Network, Source (Local or Network), Hostname, Locale (glibc), Timezone, Root password, User account, and Bootloader.
  2. Select Partition to partition with cfdisk (GPT + EFI partition at /boot/efi for UEFI, plus / partition) and select Filesystems to format and assign mount points.
  3. Choose Install to write the system and bootloader, then reboot and manage runit services via /etc/sv and /var/service.

Commands for Void Linux

void-installer sudo xbps-install -Syu sudo ln -s /etc/sv/NetworkManager /var/service/ sudo ln -s /etc/sv/dbus /var/service/

3. After installation

Independent init & system notes

Independent distributions use distinct service managers (runit, OpenRC, systemd), package tools, or source/declarative workflows. Check the official docs for service and config details.

sudo xbps-install -Syu

Practical tips for Void Linux

1. If you use the Xfce live image, select Local as the package source in void-installer unless you want network packages.

2. Enable runit services by symlinking from /etc/sv/ into /var/service/.

4. Troubleshooting

USB not booting: Re-flash the ISO with balenaEtcher or Rufus, try another USB port, and check UEFI boot priority and Secure Boot / Fast Boot settings.

Installer or boot issue: Check the official Void Linux documentation for exact partition, driver, or bootloader steps, and save your own notes in the sidebar.
