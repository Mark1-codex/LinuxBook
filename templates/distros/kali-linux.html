1. Flash the ISO to USB & boot

Download the official Kali Linux image from https://www.kali.org/get-kali/ (reference: official docs). Back up anything on your USB stick first because flashing overwrites it.

balenaEtcher (Windows, macOS, Linux)

  1. Open balenaEtcher, click Flash from file, and pick the downloaded Kali Linux ISO.
  2. Click Select target and choose your USB flash drive (verify the size/name so you do not pick an external backup drive).
  3. Click Flash! and wait for flashing and verification to complete.

Rufus (Windows)

  1. Plug in the USB stick, open Rufus, and select your USB drive under Device.
  2. Click SELECT next to Boot selection and choose your Kali Linux ISO file.
  3. Click START, confirm the data-erase warning, and wait until Rufus shows Ready.

Booting the USB: Restart and press your boot menu key (often F12, F11, F8, or Esc), select the USB drive, and disable Fast Boot / Secure Boot / Windows Fast Startup if needed.

2. Kali Linux installer & APT setup

Boot the Kali installer (or VM image) and pick Graphical install.

  1. Choose language, country, keymap, hostname, domain, and non-root user credentials.
  2. Partition the disk (guided or manual) and confirm writing changes to disk.
  3. Select desktop and tool metapackages, install GRUB, and reboot.

Commands for Kali Linux

sudo apt update && sudo apt full-upgrade -y cat /etc/apt/sources.list sudo systemctl status networking

3. After installation

Debian / Ubuntu & APT notes

APT tracks packages through .deb archives and /etc/apt/sources.list. Keep package lists refreshed before installing or upgrading software.

sudo apt update && sudo apt full-upgrade -y

Practical tips for Kali Linux

1. Prefer a virtual machine with snapshot support when practicing security tools.

2. Keep Kali packages updated with apt update && apt full-upgrade.

4. Troubleshooting

USB not booting: Re-flash the ISO with balenaEtcher or Rufus, try another USB port, and check UEFI boot priority and Secure Boot / Fast Boot settings.

Installer or boot issue: Check the official Kali Linux documentation for exact partition, driver, or bootloader steps, and save your own notes in the sidebar.
