1. Flash the ISO to USB & boot

Download the official EndeavourOS image from https://endeavouros.com/ (reference: official docs). Back up anything on your USB stick first because flashing overwrites it.

balenaEtcher (Windows, macOS, Linux)

  1. Open balenaEtcher, click Flash from file, and pick the downloaded EndeavourOS ISO.
  2. Click Select target and choose your USB flash drive (verify the size/name so you do not pick an external backup drive).
  3. Click Flash! and wait for flashing and verification to complete.

Rufus (Windows)

  1. Plug in the USB stick, open Rufus, and select your USB drive under Device.
  2. Click SELECT next to Boot selection and choose your EndeavourOS ISO file.
  3. Click START, confirm the data-erase warning, and wait until Rufus shows Ready.

Booting the USB: Restart and press your boot menu key (often F12, F11, F8, or Esc), select the USB drive, and disable Fast Boot / Secure Boot / Windows Fast Startup if needed.

2. EndeavourOS Calamares installer & post-install commands

Boot the EndeavourOS ISO in UEFI mode and select Start the Installer.

  1. Select online or offline install mode and pick your desktop environment or window manager.
  2. Choose disk partitioning (erase disk or manual partitions with /boot/efi and /) and set user credentials.
  3. Run the installation until completion, then reboot and remove the USB drive.

Commands for EndeavourOS

sudo pacman -Syu sudo pacman -S --needed linux-lts linux-lts-headers base-devel git reflector --latest 10 --sort rate --save /etc/pacman.d/mirrorlist

3. After installation

Arch & pacman rolling-release notes

Arch and Arch-based distros update continuously. Keep a fallback kernel such as linux-lts installed and avoid partial upgrades.

sudo pacman -Syu

Practical tips for EndeavourOS

1. Keep linux-lts installed as a backup kernel alongside linux.

2. Check EndeavourOS Discovery for GPU and NVIDIA driver steps.

4. Troubleshooting

USB not booting: Re-flash the ISO with balenaEtcher or Rufus, try another USB port, and check UEFI boot priority and Secure Boot / Fast Boot settings.

Installer or boot issue: Check the official EndeavourOS documentation for exact partition, driver, or bootloader steps, and save your own notes in the sidebar.
