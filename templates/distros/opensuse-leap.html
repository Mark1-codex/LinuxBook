1. Flash the ISO to USB & boot

Download the official openSUSE Leap image from https://get.opensuse.org/leap/ (reference: official docs). Back up anything on your USB stick first because flashing overwrites it.

balenaEtcher (Windows, macOS, Linux)

  1. Open balenaEtcher, click Flash from file, and pick the downloaded openSUSE Leap ISO.
  2. Click Select target and choose your USB flash drive (verify the size/name so you do not pick an external backup drive).
  3. Click Flash! and wait for flashing and verification to complete.

Rufus (Windows)

  1. Plug in the USB stick, open Rufus, and select your USB drive under Device.
  2. Click SELECT next to Boot selection and choose your openSUSE Leap ISO file.
  3. Click START, confirm the data-erase warning, and wait until Rufus shows Ready.

Booting the USB: Restart and press your boot menu key (often F12, F11, F8, or Esc), select the USB drive, and disable Fast Boot / Secure Boot / Windows Fast Startup if needed.

2. openSUSE Leap installation & zypper commands

Boot the openSUSE Leap media and start installation.

  1. Select time zone, keyboard layout, and desktop/system role.
  2. Confirm disk partitioning and create your user account.
  3. Complete installation and reboot.

Commands for openSUSE Leap

sudo zypper refresh && sudo zypper update -y sudo zypper verify

3. After installation

openSUSE & zypper / Snapper notes

Use zypper dup on Tumbleweed and zypper up on Leap, and rely on Btrfs/Snapper snapshots when testing changes.

sudo zypper refresh && sudo zypper update -y

Practical tips for openSUSE Leap

1. Use sudo zypper up for standard updates within a Leap release.

2. Back up personal files before modifying partitions.

4. Troubleshooting

USB not booting: Re-flash the ISO with balenaEtcher or Rufus, try another USB port, and check UEFI boot priority and Secure Boot / Fast Boot settings.

Installer or boot issue: Check the official openSUSE Leap documentation for exact partition, driver, or bootloader steps, and save your own notes in the sidebar.
